# MotoGarage MD

Sistema de gestión para taller mecánico de motos.  
Permite administrar clientes, motos y turnos de manera sencilla, con una interfaz uniforme y moderna.

## 🚀 Funcionalidades principales
- **Gestión de Motos**: alta, modificación y eliminación de motos.
- **Gestión de Turnos**: reservar, modificar y eliminar turnos.
- **Calendario interactivo**: muestra en **negrita** los días con turnos asignados.
- **Estilo uniforme**: todos los formularios heredan de `FormBase`, con logo y diseño consistente.

## 🛠️ Tecnologías utilizadas
- C# (.NET Windows Forms)
- Programación orientada a objetos
- DAO para acceso a datos
- Git para control de versiones
